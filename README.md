# 养鲲游戏

开局一只鲲，进化全靠吞！群聊互动养成对战游戏。

从酷Q插件「简单的养鲲游戏」移植而来，原作者 Agam

本移植版已获得原作者授权，基于 MIT 协议开源。

## 配置

在 AstrBot WebUI 插件配置页面可调整以下参数：

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| command_prefix | 命令前缀 | `*` |
| default_jie_cao | 新玩家初始节操 | 50 |
| default_luck | 新玩家初始运势 | 50 |
| egg_price | 买一颗蛋所需节操 | 5 |
| tribulation_cost | 渡劫消耗节操 | 10 |
| train_daily_max | 每日磨炼上限 | 30 |
| hatch_misfortune_rate | 悲属性孵化概率 | 0.007 (0.7%) |

## 游戏机制

### 鲲的属性

- **魑**：免疫强袭
- **魅**：免疫吞噬
- **魍**：免疫攻击
- **魉**：体重低于666千克时自动恢复至1000千克
- **淫**：被吞噬后对方75%几率死亡；攻击/被攻击25%恢复大量体重
- **馋**：吞噬失败不损失体重；不能攻击；体重>1000kg暴死
- **贪**：吞噬/攻击30%几率得蛋；磨炼70%不耗节操；放生得2-10蛋
- **惰**：极强防御，免疫强袭
- **怒**：攻击极易吞噬对方；25%致命一击
- **妒**：比其重的鲲无法对其吞噬/攻击
- **傲**：无视对方属性
- **悲**：初始体重=榜一体重+1000kg，不可幻化，孵化概率仅0.7%

### 道具

- **蛋**：买蛋/签到获得，用于孵化和喂食
- **神器(+夨￥宀♂牮√)**：砸蛋获得，用于强袭
- **幻化丹**：砸蛋获得，用于幻化鲲属性
- **鸡汤**：砸蛋获得，喝后补充节操
- **复活药**：砸蛋获得，复活无属性鲲

### BOSS 系统

每日可刷新BOSS，群友合力讨伐。击杀BOSS获得大量奖励，输出排行前5名额外获得节操奖励。

### 拍卖系统

可出售、竞拍鲲。无属性和未渡劫的鲲无法上架拍卖。上架后5分钟内不可强制下架。
